
🏛️ CivicLens

AI-Powered News & Policy Summarizer for Informed Citizens

CivicLens is designed to help citizens quickly understand complex news articles and government policies — without bias or misinformation. It uses AI to summarize content, highlight key insights, and explain real-world impact in a simple and accessible format.

🚀 Features

✅ Concise Summaries of long news & government documents
✅ Bias-Free Tone Analysis
✅ Pros & Cons Extraction for better decision-making
✅ Stakeholder Identification
✅ Impact Analysis for everyday citizens
✅ Multi-language Support (if supported by your model)
✅ User-friendly Web Interface with clean UX
✅ Secure Handling of user-provided content

🎯 Problem It Solves

Many people struggle to keep up with policies, political changes, and lengthy news content. CivicLens ensures clear understanding, enabling better civic engagement and informed decision-making.

🧠 How It Works

1️⃣ User enters a news URL or pastes policy text
2️⃣ AI extracts & analyzes key information
3️⃣ Generates:

Summary

Tone & sentiment

Pros vs Cons

Stakeholders involved

Direct impact explained

4️⃣ Presents info in a structured, readable dashboard

🛠️ Tech Stack
Layer	Tools Used
Frontend	React / Next.js / HTML / CSS
Backend	Node.js / Python API
AI	Google Vertex AI / Gemini API (or update based on your actual model)
Deployment	Cloud Run / Firebase Hosting
Database (optional)	Firestore / PostgreSQL

✅ Installation (Local Setup)
# Clone the repo
git clone https://github.com/Rylin31/CivicLens-AI
cd civiclens

# Install dependencies
npm install   # or yarn install

# Run development server
npm run dev


Add backend instructions similarly if separate.

🔐 Environment Variables

Create .env file:

GEMINI_API_KEY=your_key_here
NEWS_API_KEY=your_key_here
